# Starry Museum

Serve this static folder with any HTTP server. Edit `content.js` for the fictional profile and projects, and `index.html` for the Chinese museum labels. No install, API key, analytics or backend. WebGL enhances the exhibit; direct HTML links are provided as a fallback.

The source build, licenses and customization guide are supplied in the linked source repository. See `ATTRIBUTION.md` for painting, wood and animation credits.
